# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The security of UpPitch and our users' data is a top priority. If you discover a security vulnerability or security bug, please report it responsibly.

### Recommended Reporting Method: GitHub Private Vulnerability Reporting
Please do **NOT** file a public GitHub issue for security vulnerabilities. Instead:

1. Navigate to the [UpPitch GitHub Repository](https://github.com/HammuDev/upPitch).
2. Click on the **Security** tab.
3. Select **Report a vulnerability** to open a private advisory draft.
4. Include:
   - A clear description of the vulnerability and affected component.
   - Step-by-step reproduction steps or proof-of-concept payload.
   - Expected impact and potential mitigations if known.

### Alternative Reporting: Email
If GitHub Private Vulnerability Reporting is unavailable, you may contact the maintainers via email at the contact address listed in `lib/site.ts` (`support@uppitch.app` / repository owner).

---

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours of receiving the report.
- **Triage & Assessment**: Within 5 business days.
- **Patch & Advisory Release**: Coordinated fix deployed within 14 business days depending on severity.

Thank you for helping keep UpPitch safe for the freelance community.
